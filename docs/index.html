Lawrence Mosley · PhD dissertation · Iowa State University · 2013

A Balanced Approach to the Multi-Class Imbalance Problem

When one class dwarfs the others, accuracy rewards a model for ignoring the rare ones. This dissertation proposed Class Balance Accuracy, a metric that scores every class by the weaker of its recall and precision. This page explains the idea, lets you try it, and maps where the work has traveled since.

The idea

Class Balance Accuracy (CBA) reads a confusion matrix class by class. For each class it divides the correct predictions by whichever is larger, the number of true members or the number of predictions made for that class. Then it averages over classes.

Definition

CBA = (1 / k) · Σi cii / max(ci·, c·i)

Here cii counts the correct predictions for class i, ci· is the row total (true members), and c·i is the column total (predictions). Dividing by the larger total keeps the smaller of recall and precision for that class.

Two consequences follow. Every class counts equally, however rare. And CBA can never exceed macro recall or macro precision, so it works as a floor under both (Theorem 3.2.1 of the dissertation).

CBA is not balanced accuracy

MetricPer class it usesSees false alarms
Accuracynothing per classonly in total
Balanced accuracyrecallno
Macro precisionprecisionyes
Class Balance Accuracymin(recall, precision)yes

Balanced accuracy is the mean of per-class recall. A model that floods a small class with false alarms can keep a high balanced accuracy. CBA drops, because the precision of that class collapses.

2013 to today

The dissertation made five moves that later became common practice in machine learning. The later work listed here follows the same line of thought. It does not necessarily descend from the dissertation. The same questions now come up for deep networks and large language models, where classes have become tasks, training sets have become pre-training corpora, and ensembles have become routers.

A metric built for skewed classes
Class Balance Accuracy, Chapter 3

Later metrics extend the idea directly: relevance-weighted CBA (Branco et al., 2017), the Class Balance Metrics family (Luque et al., 2019), and the Imbalance Accuracy Metric (Mortaz, 2020). Large validation efforts such as Metrics Reloaded (2024) now treat class imbalance as a first question when choosing a metric. In foundation models the long tail sits in the pre-training data: a language model's accuracy on a fact tracks how often it appeared in pre-training (Kandpal et al., 2023), and robustness work reports worst-group accuracy next to the average (Sagawa et al., 2020).

Report several metrics, not one
Measure comparisons, Chapters 2 and 3

The dissertation compares accuracy, balanced accuracy, G-mean, F-score, MCC, and entropy measures side by side and shows where each fails. Model Cards (2019), the case for MCC over F1 and accuracy (2020), and HELM for language models (2022) made multi-metric reporting the norm. Several metrics became several benchmarks: GLUE (2019) and BIG-bench (2022) score a model on many tasks at once, and The Benchmark Lottery (2021) showed that rankings change with the choice of tasks, the way they change with the choice of metric.

Optimize the balanced objective
Instance selection by CBA, Chapter 4

Chapter 4 selects training subsets to maximize CBA instead of accuracy. Deep learning reached the same goal through the loss: focal loss (2017), class-balanced loss and LDAM (2019), and logit adjustment (2021), which targets balanced error directly. Instance selection itself returned as data pruning (2021, 2022), and DRoP (2025) found that existing pruning algorithms can produce highly biased classifiers, and set pruning ratios class by class to protect the worst-performing class.

One expert per class
Class Expert Ensembling, Chapter 5

Class Expert Ensembling assigns the best model to each class with an assignment program. Long-tailed recognition later built multi-expert models on the same intuition: LFME (2020), RIDE and ACE (2021), SADE (2022), and BalPoE (2023). Mixture-of-experts routing now runs inside large language models such as Mixtral (2024). Between models, routers pick the language model best suited to each task or query: Shnitzer et al. (2023), FrugalGPT (2023), and RouteLLM (2025).

Ship the code
The climbR package, Chapter 6

The dissertation closed with an open-source R package and a call for a shared repository of imbalance tools. That role is now filled by imbalanced-learn (2017), PyCM (2018), Multi-Imbalance (2019), and reproducibility checklists at the major conferences (2021). For language models, Hugging Face Evaluate (2022) and the lm-eval harness (2024) are shared homes for evaluation code.
